## 4. Findings requiring correction (all value-level, none conclusion-level)

1. **PC-35 (paper2 §6.2 "Scale resolution"): the 3B cost parenthetical is wrong as written.**
   Paper: *"the full-bundle cost measured at 3B (.600→.433, exact p=3.4×10⁻⁷)"*. Round-6 3B
   artifacts (`outputs/master/round6_ablation.json`): A0→A5 = **1.000→.4333** (exact p=1.164×10⁻¹⁰,
   chi2-cc 1.519×10⁻⁸); A4→A5 = .898→.4333 (28/0 flips, chi2-cc **3.352×10⁻⁷** ≈ the quoted 3.4×10⁻⁷).
   **No 3B artifact contains recall .600** — .600 is the **8B** A0 recall. Likely transcription slip;
   the qualitative claim (cost present at 3B, absent at 8B) is verified (PC-34/PC-35).
2. **PC-21 (paper2 §5 GuardDog): LCO comparison lower bound off by .012.** Paper: ".857 vs
   .735–.835". `outputs/packguard/guarddog/summary.md` comparison table (seed 20260922, t0.30):
   ours = .7473/.7636/.8000/.8155/.8350 → correct range **.747–.835** (or .723 if the later
   MalGuard-style block is included — neither equals .735). "Top at t0.30, reverses at t0.50"
   (.855 vs .865–.898) both hold.
3. **PC-29 (paper2 §6.3): "n=500" next to the no-empty-graph F1 is ambiguous.** F1 0.8205 is real
   (`fl/results.jsonl` `group__graph__noempty__centralized`) but is measured on the group-split
   **test rows of the 500-row with-graph subset (n_test=79)**; 500 is the subset size, not the
   eval n.
4. **PC-36 (STALE): `outputs/packguard/r16_kaggle/r16_analysis.json` still says `status: "pending"`
   (dated 14:24:10Z) although the Kaggle results landed 14:26/14:56Z.** The registered AMENDMENT-9
   analysis harness was never re-run after download. The paper's Kaggle numbers are nonetheless
   **correct** — independently recomputed from the raw `results_*.jsonl` (PC-34) — but the
   analysis artifact should be regenerated (`kaggle_pkg/analysis.py`) before artifact release.
5. **RG-32 (paper §6): "all 473 defence records"** is the round-5 V2-audit *deduplicated* count
   (llama 180 + qwen 293, `reports/round5/V2_report.md` L79: "473/473 … 0 REFUSAL, 0 PARTIAL");
   raw run+control records are 960 (counted this session). True as written in the audit's sense,
   but the wording invites a misreading; a parenthetical would fix it.
6. **Minor comment-path drift (RG-28):** `tables/tab_codebert.tex` cites
   `final_eval.json -> final_eval_pilot_arm.metrics`; the actual path is
   `final_eval.json -> transformer_b4.final_eval_pilot_arm.metrics`. Values identical.
