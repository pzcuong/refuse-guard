\section{Reproducibility and Artifact Appendix}
\label{app:repro}

\subsection{Artifact overview}
\begin{sloppypar}
The complete implementation, experiment outputs, and this paper's sources live
in a single repository. Code layout:
\code{src/data} (PrimeVul loading/validation, seeded stratified sampling,
benchmark build, safety-contrast set),
\code{src/conditions} (C0--C3 generators with tree-sitter
semantic-preservation checks, plus \code{c5_risk_context.py} --- the
content-anchored C5 advisory attack: AST sink extraction, label-blind
advisory templates, arm materialization),
\code{src/defenses} (B1 reframe, B2 comment stripping, B3 aggressive
removal, P1 semantic context isolation, P2 gate-first pipeline,
\code{p3_boundary.py} --- advisory detection, provenance boundary label,
task-intent reassertion, refusal recovery),
\code{src/models} (cached/resumable LLM harness, refusal monitor, CodeBERT
baseline, fusion policy),
\code{src/metrics} (RR/UAC/SIUD/DRR/CUL/MCC, McNemar and bootstrap),
\code{src/experiments} (runners, incl.\ \code{round5_e0v2.py},
\code{round5_defense.py}, and \code{round6_ablation.py} --- the
pre-registered P3 component ladder, C5 extension, and qwen spot check),
and \code{scripts} (training, evaluation, calibration, audit recomputes,
\code{collect_master_round5.py}, \code{collect_master_round6.py},
\code{collect_master_round7.py},
\code{analyze_verdict_bias.py}). Pre-registrations are frozen in
\code{configs/e*_round3.yaml}, \code{docs/e0_protocol.md}, the
round-5 gates in \code{configs/attack_v2.yaml},
\code{configs/round5_e0v2.yaml}, \code{configs/round5_defense.yaml},
the round-6 ablation in \code{configs/round6_ablation.yaml}
reconciled with \code{docs/round6_ablation_prereg.md} (+ Amendment-1),
and Round 7 in \code{docs/round7_prereg.md} (+ Amendment-1) with
\code{configs/attack_v2_cwe.yaml} and \code{configs/round7_7b.yaml};
every output records model id, revision, seed, config hash, and date.
\end{sloppypar}

\subsection{Environment}
All experiments ran on Apple silicon (M2 Pro, 32\,GB) with the MPS backend,
Python 3.12, pinned dependencies (\code{requirements.txt},
\code{requirements-lock.txt}; torch 2.14, transformers 5.17). No paid API is
used: the three study models are open-weight
(Qwen2.5-Coder-3B-Instruct~\cite{hui2024qwen25coder},
Llama-3.2-3B-Instruct~\cite{grattafiori2024llama3},
granite-3.3-2b-instruct~\cite{granite2025modelcard}) and run locally.
The paper PDF builds with \code{tectonic paper/main.tex}.

\subsection{Reproducing the experiments}
\begin{sloppypar}
In order: (1)~\code{scripts/download_data.py} downloads the PrimeVul mirror
(Hugging Face \code{starsofchance/PrimeVul}) and the OR-Bench/XSTest contrast
corpora into \code{data/raw/}, after which \texttt{python -m src.data.primevul}
validates the counts against the PrimeVul paper~\cite{ding2025primevul};
(2)~\code{src.data.sampling} builds the seeded
subsets; (3)~\code{src.data.bench_build} materializes the paired benchmark,
the E8 contrast set, and the E0 prompts; (4)~\code{scripts/train_codebert.py}
and \code{scripts/eval_codebert.py} train/evaluate B4; (5)~
\code{scripts/calibrate_refusal_monitor.py} fits monitor thresholds on the
disjoint calibration half only; (6)~the round-3 runners execute
E0/E2/E3/E4 (\code{src.experiments.round3_scaleup}, stages
\code{e0}/\code{e2e3}/\code{e4}/\code{gate}) and
E5/E6/E8 (\code{src.experiments.pilot_round3}); (7)~
\code{scripts/run_e7_fusion.py} evaluates the fusion policy without any LLM
call; (8)~\code{src.experiments.round5_e0v2} (stages \code{dry}/\code{smoke}/
\code{run}/\code{verdict}/\code{summary}) and
\code{src.experiments.round5_defense} execute the C5 transfer study and the
P3 defence audit; (9)~\code{scripts/collect_master_round5.py} aggregates
every round-5 number into \code{outputs/master/round5_master.json} with a
re-read verification; (10)~\code{src.experiments.round6_ablation}
(stages \code{dry}/\code{run}/\code{extend}/\code{metrics}) executes the
Round-6 component ladder, C5\_far culprit confirmation, C5 power
extension, and the qwen A1-vs-A5 spot check, and
(11)~\code{scripts/collect_master_round6.py} aggregates every round-6
number into \code{outputs/master/round6_ablation.json}
(re-read verified; exact-binomial McNemar recomputed with the runner's
continuity-corrected $\chi^2$ variants stored alongside), while
\code{scripts/analyze_verdict_bias.py} produces
\code{outputs/master/round6_bias.json} the same way;
(12)~\code{scripts/final_eval_summary.py} aggregates master results;
(13)~Round 7 runs \code{src.experiments.round7_rq8} (CWE-generalization
arm) and \code{src.experiments.round7_7b} (stages
\code{smoke}/\code{run}/\code{benign}/\code{metrics}), and
(14)~\code{scripts/collect_master_round7.py} aggregates every round-7
number into \code{outputs/master/round7_master.json} +
\code{round7_token_map.json} (exact discordant-only McNemar recomputed
from records; verdicts computed by the registered rules; re-read verified).
All LLM calls are content-addressed and cached in \code{outputs/llm_cache/};
any rerun resumes from cache. A smoke verification without training or
generation (\code{bash scripts/verify_repro.sh}) checks the test suite
(strict ``$N$ passed, zero failed''), a dry-run of the E2 runner, existence
and parseability of every artifact the paper cites, decision-critical values
(gate verdict, recomputed E8, master-row count, round-7 verdicts and
headline numbers, token-map-vs-paper consistency), the SHA256 artifact
manifest (\code{scripts/make_manifest.py}), and the PDF build.
\end{sloppypar}

\subsection{Deviations and disclosures}
Round-3 deviations are disclosed in the reports shipped with the artifact:
the E0 gate's PASS branch is unattainable at the registered $n=20$ paired
functions (a $\Delta$RR of $\geq 0.30$ would be required for McNemar
significance at this $n$~\cite{mcnemar1947note}), so the observed verdict is a
fail with effect size exactly zero; the Qwen monitor's original fit conflated
model over-refusal with instrument error (legacy over-refusal 0.587 vs.\
$\leq 0.10$ registered) --- round-10 re-fit with silver gold non-refusals
shows monitor false-refusal $=0.000$ for both models (criterion PASSES) and
true model strong over-refusal $=0.520$ on Qwen, carried as an explicit
model-level caveat on all monitor-derived refusal rates; and the bootstrap
confidence intervals use
$10{,}000$~resamples~\cite{efron1979bootstrap} with the seed published in each
results file. Round-6 disclosures: the ladder's per-rung McNemar $p$
values are two-sided exact binomial, with the pre-registered stats
module's continuity-corrected $\chi^2$ variant stored alongside wherever
the discordant count reaches 25 (conservative in every affected cell; no
verdict changes); the first qwen spot-check run was quarantined for
cross-model cache-reuse contamination and re-run clean (0 records
reused), so its 131 burned generations appear in the budget but in no
table; Round-6 GPU generations total 834 --- 703 in the final files
(325 ladder + 160 llama extension + 160 granite extension + 58 C5\_far)
plus the 131 discarded ones.
