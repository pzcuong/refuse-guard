$\Delta$ vs.\ A0 is the recall change relative to raw B0; $p$ is the
two-sided exact binomial McNemar test of each rung against the previous
rung (the pre-registered stats module returns a continuity-corrected
$\chi^2$ approximation when the discordant count is $\geq 25$; both
variants are stored in the artifact, the $\chi^2$ value is the conservative
one, and no verdict changes). A3/A4 recall uses 59/60 parsed records (one
unparseable \textsc{partial}); $\Delta$ and $p$ are computed on parsed
pairs. Pre-registered thresholds: component-attributable harm $=$
$\Delta$(rung$\to$rung) $\geq 0.20$ with $p<0.05$ (H-M1); minimal variant
safe $=$ $\Delta$(A0$\to$A1) $\leq 0.05$ vs.\ B0 (H-M2); if no rung
qualifies but A0$\to$A5 does, the harm is bundle-synergy by rule. A second
pre-registered framing (concentration: the rung with the largest single-step
flip count; ``distributed'' if no rung holds $\geq$50\% of the total
A5-vs-A0 flips) is reported alongside.}
